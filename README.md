⚡ AutoFlow – Workflow Automation Platform

AutoFlow is a Python-based workflow automation platform built with Streamlit.

Features

- Professional automation dashboard
- Create and manage workflows
- Automated scheduling
- Workflow templates
- Execution history and retry
- JSON reports and CSV backups
- Webhook integration
- Execution analytics

Tech Stack

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- APScheduler
- Requests

Inwstallation

pip install -r requirements.txt

Run Application

streamlit run app.py

Project Purpose

Built as a portfolio project to demonstrate Python programming, database operations, workflow automation, and dashboard development.

Future Improvements

- Real AI integration
- Email notifications
- Drag-and-drop workflow builder
- Cloud deployment
